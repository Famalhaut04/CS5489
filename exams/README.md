# CS5489 历年期中与期末试题

[打开试题入口](../exams.html) · [返回课程目录](../index.html)

本入口用于后续按年份补充试卷。没有核实来源的本地文件不自动上线；空目录不代表该课程从未有考试。

## 分类约定
- `midterm`：有明确来源支持的期中试题。
- `final`：有明确来源支持的期末试题。
- `mock`：模拟卷或考前练习，不标为真题。
- `sample`：样题，不标为历年真题。
- `notice`：考试规则或安排，不标为试卷。
- 题目 `questions`、教师官方答案 `official-solutions`、参考材料 `reference` 分开标记。
- 学年、学期、考试年份和 A/B 场次按来源记录；不要用下载年份猜考试年份。无法确定时 `exam_year` 为 null。

## 后续补充流程
1. 提供来源链接、课程、年份／学年、学期、试卷类型、题目／答案角色；模板见 submission-example.json。
2. 核验来源与可公开性，排除姓名学号、座位、成绩、凭据及未公开考试内容。
3. 文件只保存到对应课程仓库，按内容 SHA256 去重；外部来源明确标注，不能冒充 Canvas。
4. 更新 catalog.json，目录和下载包由维护脚本重建，再检查链接和压缩包。
5. 经维护者审阅后发布新的 Releases，并刷新统一门户的元数据。

当前只有 Canvas 来源已核实资料进入本批下载包。外部搜索到的候选题目可先通过 Issue 提交来源线索，不会直接公开上传。
